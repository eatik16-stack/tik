# Tik

İki kişilik günlük iş listesi. Telefondan kullanılan tek sayfalık bir web uygulaması.

- Arayüz: GitHub Pages (`index.html`)
- Veri ve giriş: Supabase (`tik-gunluk-liste`). Erişim, veritabanı kurallarıyla iki üyeyle sınırlıdır.
- `keep-alive.yml`: Ücretsiz Supabase projesinin kullanılmadığında duraklamaması için üç günde bir veritabanına dokunur.
